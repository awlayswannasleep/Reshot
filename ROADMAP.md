# RESHOT — План разработки по фазам

> **Состояние на 2026-07-28: фазы 0–6 пройдены, выпущена версия 1.0.0.**
>
> Реализованное сверх этого плана: OCR (копирование текста с картинки), радиальное меню
> по удержанию хоткея, раздельная запись звуковых дорожек с выбором после остановки,
> запись звука отдельных приложений, мягкие ластики, оформление в духе Half-Life 2 и
> окно настроек на Tauri вместо WPF.
>
> Не сделано из фазы 5: автообновление (Velopack). Ключ `update.auto` присутствует в
> настройках, но ни на что не влияет. Список расхождений и ограничений —
> в [CHANGELOG.md](CHANGELOG.md).

Принципы:

- Каждая фаза заканчивается **рабочей программой**, которой уже можно пользоваться.
- Не начинать фазу N+1, пока не закрыт Definition of Done фазы N.
- Дедлайнов нет — фазы упорядочены по зависимостям и по принципу «максимум пользы раньше».
- Как работать с Claude: на каждую задачу давать контекст = SPEC.md (нужные разделы) + ARCHITECTURE.md (§ по теме) + текущий код. Просить небольшие инкременты, после каждого — собирать и запускать руками.

## Фаза 0 — Скелет и инфраструктура

Цель: программа живёт в трее, просыпается по хоткею, ничего не жрёт.

- [ ] Solution по структуре из ARCHITECTURE §2 (App / Core / Capture + tests)
- [ ] Git-репозиторий, лицензия (MIT), базовый README проекта
- [ ] Трей-иконка с меню: Capture, Settings (заглушка), Quit
- [ ] Глобальный хоткей `PrtScn` через RegisterHotKey; обработчик пишет в лог
- [ ] Single instance (mutex; второй запуск — сигнал первому)
- [ ] Settings: загрузка/сохранение JSON в `%AppData%\reshot\`, дефолты из SPEC §13
- [ ] Автозапуск через реестр (вкл/выкл, по умолчанию вкл)
- [ ] Ребиндинг хоткея (пока правкой JSON; UI — в Фазе 5)

**Definition of Done:** exe запускается, висит в трее; диспетчер задач показывает ~0% CPU и <30 МБ RAM в простое; хоткей срабатывает из любого приложения; после перезагрузки Windows программа стартует сама.

## Фаза 1 — Захват, оверлей, прямоугольное выделение, вывод

Цель: минимальный полезный продукт — скриншот области в буфер/файл. С этого момента программой можно пользоваться каждый день.

- [ ] `Reshot.Capture`: снимок всех мониторов через Windows.Graphics.Capture → единый битмап виртуального десктопа (без курсора, без жёлтой рамки)
- [ ] Полноэкранный borderless-оверлей с замороженным кадром и затемнением (цвет/сила из настроек, дефолт чёрный 50%)
- [ ] Появление оверлея < 150 мс (окно переиспользуется, см. ARCHITECTURE §7)
- [ ] Прямоугольное выделение: drag → зона без затемнения, live-обновление
- [ ] Рамка выделения: 8 ручек = ресайз, захват за ребро = перемещение
- [ ] `Shift`: 1:1 с самого начала; фиксация текущего ratio, если зажат в процессе
- [ ] `Ctrl+A` — основной монитор; повторный `Ctrl+A` — все мониторы
- [ ] `Ctrl`+drag — мультивыделение (несколько активных областей)
- [ ] Тулбар: справа снизу снаружи, перенос внутрь при нехватке места; пока кнопки Copy / Save / Save As
- [ ] Copy → PNG в буфер; Save → папка из настроек с шаблоном имени; Save As → диалог
- [ ] `Esc`: снять выделение → закрыть сессию; `Enter` = Copy + закрыть (O-6)
- [ ] Конечный автомат сессии из ARCHITECTURE §8 (с состоянием Recording-заглушкой)

**Definition of Done:** цикл «PrtScn → выделил → Copy → Ctrl+V в Discord/Telegram» работает быстро и без глюков на 2 мониторах; выделение двигается и ресайзится; Ctrl+A×2 отдаёт оба монитора одним кадром.

## Фаза 2 — Формы выделения и тулбар инструментов

Цель: вся механика выделения из SPEC §4 и каркас тулбара с подменю.

- [ ] Тулбар: 5 кнопок инструментов, хоткеи `1`–`5`, ПКМ → вертикальное подменю подинструментов
- [ ] Ellipse: выделение эллипсом, Shift-логика как у прямоугольника
- [ ] Lasso: свободный контур, автозамыкание прямой от конца к началу
- [ ] Polygon: точки-клики; замыкание кликом в первую точку или ПКМ (кратчайшая дистанция)
- [ ] Triangle
- [ ] Все формы → bounding box с теми же ручками; вне контура — прозрачность
- [ ] Экспорт (Copy/Save) непрямоугольных форм: PNG с корректной альфой
- [ ] Мультивыделение с разными формами; экспорт по O-1 (общий bounding box, между областями прозрачность)
- [ ] Перевыделение: старая область и её правки удаляются (с Ctrl+Z — см. Фазу 3, пока просто удаление)

**Definition of Done:** любой формой можно выделить, подвигать, отресайзить и получить корректный PNG с прозрачностью (проверка: вставка в редактор с шахматным фоном).

## Фаза 3 — Рисование: кисть, фигуры, текст, пипетка, undo

Цель: полный инструмент 2 + история.

- [ ] Модель слоёв из ARCHITECTURE §3 (Base / Effects / Paint / Vector) — фундамент фазы
- [ ] Кисть: HEX-палитра, непрозрачность, толщина; мазки в PaintLayer (перманентный растр)
- [ ] Панель настроек рисования по `Shift`
- [ ] Пипетка: зажатие ПКМ на холсте → квадрат-превью цвета над курсором (+HEX), отпускание = выбор; ПКМ по тулбару — приоритет меню
- [ ] Фигуры: круг, квадрат, линия, треугольник, стрелка — векторные объекты в VectorLayer
- [ ] Выбор/перемещение векторных объектов после создания (hit-test)
- [ ] Текст: ввод, шрифт, размер, цвет; движимый векторный объект
- [ ] Ограничение всех правок контуром выделения (клип по Selection.ShapePath)
- [ ] Undo/Redo: command-стек 32 шага, тайловые снапшоты для растра (ARCHITECTURE §5); покрывает и смену выделения
- [ ] Порядок отрисовки при экспорте: base → paint → vector, обрезка по контуру

**Definition of Done:** сценарий «скриншот → обвести кнопку стрелкой → подписать текстом → подвинуть текст точнее → Ctrl+Z пару раз → Copy» работает без артефактов; undo не раздувает память (проверить на 20+ мазках по 4K).

## Фаза 4 — Ластики и эффекты

Цель: инструменты 3 и 4 целиком.

- [ ] Общий движок штампа с hardness-моделью (ARCHITECTURE §4): центр всегда 100%, falloff по силе; переиспользуется кистью
- [ ] Eraser: стирает PaintLayer + удаляет векторные объекты при попадании (или растеризует-и-стирает — решить на месте, задокументировать)
- [ ] Absolute Eraser: стирание всего до прозрачности (маска на композицию)
- [ ] Blur: кистью по умолчанию, `Ctrl` — прямоугольная зона; сила и размер по `Shift`
- [ ] Pixelize: то же, сила = размер пикселя
- [ ] EffectsLayer поверх нетронутого оригинала
- [ ] Filter Eraser: стирает только EffectsLayer, возвращая оригинальные пиксели
- [ ] Все три ластика: меню настроек (размер, сила) по `Shift`
- [ ] Undo для всех новых операций
- [ ] Прогон производительности: мазки блюра по 4K-области держат отзывчивость (даунскейл превью при необходимости)

**Definition of Done:** сценарий «скриншот переписки → замазать ники пикселизацией → одно место замазал лишнее → Filter Eraser вернул → Save» работает; hardness визуально совпадает с референсом Photoshop (мягкое пятно ↔ жёсткий круг).

## Фаза 6 — Запись видео

Цель: инструмент 5 по SPEC §9. Делается последней, но опирается на закладки Фаз 1–2.

- [ ] `Reshot.Capture.StartStream()`: живой поток кадров области (frame pool, кроп)
- [ ] Кодирование: Media Foundation SinkWriter, H.264 аппаратно (NVENC/AMF/QSV), MP4; FPS из настроек (60/30/25)
- [ ] Кнопка Record в тулбаре (`5`): выделение любой формы → запись её прямоугольного bounding box
- [ ] Переход в состояние Recording: весь UI редактирования скрывается
- [ ] Индикатор справа сверху: красная лампочка, таймер, разрешение
- [ ] Уголки границ области: отдельное click-through окно; настройки вкл/цвет/прозрачность
- [ ] Стоп по главному хоткею
- [ ] Аудио: WASAPI loopback (система) + capture (микрофон) → две дорожки
- [ ] Окно сохранения: тумблеры дорожек; обе включены → микс в одну в финальном MP4
- [ ] Настройки: отключение окна сохранения (фиксированный выбор дорожек), выбор устройства микрофона
- [ ] Save/Save As в `Videos\reshot`; Copy к видео не применяется
- [ ] Прогон: 60 FPS 1440p-область 10 минут — без дропов и рассинхрона звука

**Definition of Done:** сценарий «выделил окно игры → Record → поиграл 2 минуты с микрофоном → PrtScn → сохранил только системный звук → MP4 играет везде со звуком в синхроне».
